# Portfolio

A personal portfolio website built with React, Vite, and Tailwind CSS.

## Features

- Responsive, mobile-first layout
- Light/dark theme toggle with `localStorage` persistence
- Animated sections (Framer Motion) with scroll-based reveals
- Sticky navbar with active-section highlighting
- Hero, About, Skills, Projects, Experience, and Contact sections
- Client-side validated contact form
- All content driven by `src/data/portfolio.js` — edit that file to personalize

## Getting started

```bash
npm install
npm run dev
```

## Build

```bash
npm run build
npm run preview
```

## Customizing

Edit `src/data/portfolio.js` to update your name, bio, skills, projects, and experience. Colors and theme tokens live in `src/index.css`.
